# @achoo254/chat-proto

The client/server contract of the [chat-next](https://github.com/achoo254/chat-next) server: messages, enums
and Connect service descriptors generated by [Protobuf-ES](https://github.com/bufbuild/protobuf-es) v2 from
[`proto/app/v1`](https://github.com/achoo254/chat-next/tree/main/proto/app/v1). One subpath per proto file:
`auth`, `bot_admin`, `bots`, `chats`, `config`, `feedback`, `integrations`, `media`, `messages`, `moderation`,
`privacy`, `push`, `realtime`, `search`, `updates`, `users`. 64-bit ids are JavaScript numbers (`jstype =
JS_NUMBER`, always below 2^53).

Do not edit: the files are regenerated with `pnpm proto:gen` in the repository.

The API is `0.x`: it may change in any minor release until 1.0. Pin the exact version.

## Install

```sh
npm install @achoo254/chat-proto @bufbuild/protobuf @connectrpc/connect @connectrpc/connect-web
```

pnpm 11 refuses versions published less than 24 hours ago (`minimumReleaseAge`, 1440 minutes by default). To
install a release on its first day, list that exact version in `pnpm-workspace.yaml`:

```yaml
minimumReleaseAgeExclude:
  - "@achoo254/chat-proto@0.1.0"
```

## Usage

```ts
import { createClient } from "@connectrpc/connect";
import { createConnectTransport } from "@connectrpc/connect-web";
import { UsersService } from "@achoo254/chat-proto/users";

// Same origin as the page: the server authenticates the web with its session cookie.
const users = createClient(UsersService, createConnectTransport({ baseUrl: `${location.origin}/rpc` }));
const self = await users.getSelf({});
```

Every RPC checks the `Origin` header against the server's `CHAT_PUBLIC_URL`; see
[`@achoo254/chat-platform-web`](https://www.npmjs.com/package/@achoo254/chat-platform-web) for the same-origin
setup.

## Server requirements

There is no default server: you run your own [chat-next server](https://github.com/achoo254/chat-next/tree/main/server)
(Go, PostgreSQL 16, an OpenID Connect provider) and point the client at it. Environment, routes and roles:
[`server/README.md`](https://github.com/achoo254/chat-next/blob/main/server/README.md); how a web page reaches it
(same origin, reverse proxy): [`@achoo254/chat-platform-web`](https://www.npmjs.com/package/@achoo254/chat-platform-web).
